# Discovery 기능 데이터 소스 리서치 (2026-07-28)

PRD(탐색 — 장소 탐색 · 맞춤 추천 · AI 여행 루트 · 카카오내비 연동) 구현에 필요한
무료 API/데이터 소스 조사 결과. 공모전 조건: 관광공사 OpenAPI 최소 1개 이상 사용.

---

## 1. 필수 — 한국관광공사 반려동물 동반여행 서비스 (`KorPetTourService2`)

- 포털: https://www.data.go.kr/data/15135102/openapi.do
- Base URL: `https://apis.data.go.kr/B551011/KorPetTourService2` (버전 **2** — `KorPetTourService1`은 무효 경로, 실제 엔드포인트 프로브로 검증됨)
- 인증: 공공데이터포털 활용신청 → serviceKey. 무료, 개발계정 **1,000건/일** (운영계정 전환 시 증량 신청 가능)
- 오퍼레이션 13개 (검증 완료):
  - 목록: `areaBasedList2`(지역), `locationBasedList2`(위경도+반경, 거리순), `searchKeyword2`
  - 상세: `detailCommon2`, `detailIntro2`, `detailInfo2`(반복정보), `detailImage2`, **`detailPetTour2`**
  - 코드: `ldongCode2`(법정동), `lclsSystmCode2`(신분류) — ⚠️ `areaCode2`/`categoryCode2`는 "삭제예정" 명시, 신규 개발에 쓰지 말 것
  - 동기화: `petTourSyncList2` (이 서비스 고유 — 변경분 동기화용)
- 콘텐츠 타입: 관광지(12)·문화시설(14)·축제(15)·레포츠(28)·숙박(32)·쇼핑(38)·음식점(39)
- 목록 응답 필드: `contentid`, `contenttypeid`, `title`, `addr1/2`, `mapx/mapy`(WGS84), `firstimage/firstimage2`, `cpyrhtDivCd`(이미지 저작권), `tel`, `cat1~3`, `lclsSystm1~3`, `createdtime/modifiedtime`

### `detailPetTour2` 응답 필드 (전량)

| 필드 | 의미 |
|---|---|
| `acmpyTypeCd` | 동반유형코드 (enum 체계 미확인 — 키 발급 후 실측 필요) |
| `acmpyPsblCpam` | 동반가능동물 |
| `acmpyNeedMtr` | 동반 시 필요사항 |
| `etcAcmpyInfo` | 기타 동반 정보 |
| `relaAcdntRiskMtr` | 관련 사고 대비사항 |
| `relaPosesFclty` | 관련 구비 시설 |
| `relaFrnshPrdlst` / `relaPurcPrdlst` / `relaRntlPrdlst` | 비치/구매/렌탈 품목 |

> **핵심 함정**: 견종/크기 제한, 리드줄, 입마개, 케이지, 동반 요금의 **구조화 필드가 없다.**
> 전부 `acmpyPsblCpam`, `acmpyNeedMtr` 등 자유 텍스트 안에 서술형으로 들어 있음.
> → PRD의 "동반 조건 배지"와 개인화 필터(크기/견종 입장 가능)를 만들려면
> **텍스트 파싱/정규화 레이어(LLM 배치 전처리)가 필수.**

## 2. 보강 — 한국관광공사 국문 관광정보 서비스 (`KorService2`)

- 포털: https://www.data.go.kr/data/15101578/openapi.do
- Base URL: `https://apis.data.go.kr/B551011/KorService2` (최신 버전 2 확인)
- 무료 1,000건/일. 약 26만 건, 15개 오퍼레이션
- **contentId가 KorPetTourService2와 호환** (KorService2 자체에도 `detailPetTour2`가 포함됨)
- 용도: `detailImage2`(서브이미지+저작권), `detailIntro2`(쉬는날/개장기간), `detailInfo2`(영업시간 등 반복정보)로 장소 상세 보강

## 3. AI 루트 추천 근거 — 연관 관광지 서비스 (`TarRlteTarService1`)

- 포털: https://www.data.go.kr/data/15128560/openapi.do
- **Tmap 내비 실이동 데이터 기반** 관광지별 연관 방문지 랭킹 (전체/관광/음식/숙박별 최대 50위, 집계 2024.5~2025.4)
- 오퍼레이션: `areaBasedList1`, `searchKeyword1`. 무료 1,000건/일
- 용도: AI 루트 생성 시 "이 장소 다음에 실제 사람들이 가는 곳" 근거 데이터

## 4. 동반 조건 구조화 시드 — 한국문화정보원 전국 반려동물 동반 가능 문화시설

- 포털: https://www.data.go.kr/data/15111389/fileData.do
- **CSV 70,650행** (무료 다운로드) + 표준 OpenAPI
- 필드: 시설명, 카테고리, 주소, **위경도**, 운영시간, 휴무일, 주차, 입장료, 실내/실외,
  **동반 가능정보, 반려동물 전용 정보, 입장 가능 동물 크기, 제한사항, 애견 동반 추가 요금**, 최종작성일
- ⚠️ 사실상 정적 스냅샷(2022-12 구축, 2025-03 보완, "수시/1회성") — 폐업/정책변경 미반영.
  `최종작성일` 기준 신선도 라벨 필요. contentId 없음 → 관광공사 데이터와 **이름+좌표 매칭** 필요
- 가치: 관광공사 API에 없는 **크기·추가요금 구조화 컬럼** 보유 → 개인화 필터의 핵심 보강 소스

## 5. 카카오 계열 (루트 계산 + 내비 연동)

| API | 방식 | 경유지 | 무료 쿼터 | 용도 |
|---|---|---|---|---|

| 카카오맵 앱 스킴 | `kakaomap://route` + `vp`~`vp5` | **5개** | 무료, 앱 키 불필요 | 내비 폴백 (대중교통은 경유지 미지원) |

| 카카오모빌리티 미래 운행 정보 | REST | 미확인 | 일 5,000건 | 출발시각 기준 예측 소요시간 |
| 카카오 로컬 (키워드/카테고리/좌표변환) | REST | — | 각 일 100,000건 | 지오코딩·장소 매칭 (반려동물 카테고리 코드 없음) |
| 카카오맵 Web SDK | JS | — | 일 300,000건 | 지도 표시 |

- **결론: PRD의 "경유지 한도 초과 시 분할 전략"은 필수.** 내비 3개 한도 → (a) 카카오맵 스킴(5개) 폴백, (b) 3경유지 단위 분할 순차 안내 UX
- 대안 비교: 네이버 NCP Directions 15(경유지 15개, 무료량 API별 상이·미확인), TMAP(경유지 5개 + 경유지 순서 최적화 API 최대 100개, 무료 일 1,000건)
  → **TMAP 경유지 최적화 API는 카카오에 없는 기능이라 루트 순서 최적화에 검토 가치 있음**

## 8. 수집·가공 파이프라인 (제안)

1. **초기 적재(배치)**: `areaBasedList2` 전 지역 페이징 → contentId별 `detailPetTour2` + `detailCommon2` 병합 → 자체 DB.
   ⚠️ 일 1,000건 한도 → 장소 수천 건이면 초기 풀수집에 수일 소요 가능. 운영계정 증량 신청 or 수집 순서(수도권 우선) 전략.
2. **증분 동기화**: `petTourSyncList2` + `modifiedtime` 기준 일 배치.
3. **구조화(가공)**: 자유텍스트(동반가능동물/필요사항 등)를 LLM 배치로
   `{허용 크기, 견종 제한, 리드줄, 입마개, 케이지, 동반 요금, 실내/실외 허용}` 스키마로 추출.
   추출 실패/모호 → PRD의 "동반 정책 확인 필요" 라벨.
4. **크로스 검증**: 문화정보원 CSV 70,650건과 이름+좌표(카카오 로컬 지오코딩) 매칭 → 크기/요금 컬럼으로 LLM 추출값 검증·보강.
5. **서빙**: 실시간 API 프록시는 쿼터상 불가 — 자체 DB에서 서빙, 관광공사 API는 수집 전용.
